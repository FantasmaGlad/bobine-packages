Dépôts Linux Officiels

Dépôts de paquets signés et optimisés pour toutes les distributions Linux majeures. Architectures x86_64 et aarch64 (ARM64).

Certifié pour Framework Laptop (AMD Ryzen, Intel Core Ultra, Qualcomm Snapdragon ARM)
1 Importer la clé de signature OpenPGP
sudo install -m 0755 -d /etc/apt/keyrings curl -fsSL https://packages.bobine.fit/bobine.gpg | sudo tee /etc/apt/keyrings/bobine.gpg > /dev/null
2 Ajouter le dépôt Bobine
echo "deb [signed-by=/etc/apt/keyrings/bobine.gpg] https://packages.bobine.fit/debian stable main" | sudo tee /etc/apt/sources.list.d/bobine.list
3 Mettre à jour et installer Bobine
sudo apt update && sudo apt install bobine
1 Ajouter le dépôt DNF
sudo dnf config-manager addrepo --from-repofile=https://packages.bobine.fit/fedora/bobine-stable.repo
2 Installer Bobine
sudo dnf install bobine
ℹ Pour RHEL / AlmaLinux / Rocky Linux (dnf 4)
sudo dnf config-manager --add-repo https://packages.bobine.fit/fedora/bobine-stable.repo sudo dnf install bobine
1 Importer et certifier la clé locale pacman
curl -fsSL https://packages.bobine.fit/bobine.gpg | sudo pacman-key --add - sudo pacman-key --lsign-key B77D96D72F84F36ACAA3F8729CBF497D829EE15A
2 Ajouter le miroir pacman (/etc/pacman.conf)
sudo tee -a /etc/pacman.conf << 'EOF' [bobine] SigLevel = Required DatabaseOptional Server = https://packages.bobine.fit/arch/stable/$arch EOF
3 Synchroniser et installer
sudo pacman -Sy bobine
