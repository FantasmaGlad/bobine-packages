Architectures

Targeted processors

Bobine is built natively for x86_64 (amd64) and ARM64 (aarch64), without emulation.

x86_64 (Intel and AMD)

Intel Core, Core Ultra and N-series processors, AMD Ryzen, Dell Wyse 5070 class thin clients and mini PCs for 24/7 use.

ARM64 (Snapdragon, Apple Silicon, single-board computers)

Snapdragon X laptops, ARM tablets with USB-C video output, Raspberry Pi 5 and similar boards.

Compatibility lists are targets, not hardware validations: each device is validated on real hardware before it is announced as validated. Details on the Bobine site. See the compatibility pages.

Security

One OpenPGP signature for every repository

Repository indexes (InRelease, repomd.xml.asc, bobine.db.sig) and packages are signed with the same key. Your package manager rejects a file that was altered.

Signing key fingerprint

Check that the fingerprint shown by your package manager matches this one:

B77D 96D7 2F84 F36A CAA3 F872 9CBF 497D 829E E15A

Inspect the key directly: curl -fsSL https://packages.bobine.fit/bobine.gpg | gpg --show-keys

Distribution notes

  • Fedora and RPM Fusion : Fedora ships ffmpeg-free by default. Enable RPM Fusion, then run sudo dnf swap ffmpeg-free ffmpeg --allowerasing for the full codec set.
  • RHEL 9, AlmaLinux, Rocky Linux : Enable EPEL first (sudo dnf install epel-release) so the multimedia and WebKitGTK dependencies resolve.
  • Updates from the app : Bobine detects whether it was installed with dpkg/apt, rpm/dnf or pacman and updates itself in the same format, through Polkit.
Other platforms

Windows, macOS, Android and browsers

Bobine also installs on other systems and is controlled from any modern browser on the local network.

Windows and macOS

Installers for Windows (x86_64, ARM64) and a disk image for Apple Silicon Macs.

Android, Google Book and Android TV

An APK for tablets and Google Book, and an APK for Android TV and Google TV boxes.

Browsers and Tor

Remote control from Firefox, Chrome, Edge, Brave, Safari and Tor Browser, with a Tor mirror of the site and of these repositories.

Autonomous video and audio playout, free software under AGPL-3.0. OpenPGP key 829EE15A.
