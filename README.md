# packages.bobine.fit

Signed APT, DNF and Pacman repositories for [Bobine](https://github.com/FantasmaGlad/Bobine), on x86_64 and aarch64. French: [README.fr.md](README.fr.md).

- Signing key: https://packages.bobine.fit/bobine.gpg
- Fingerprint: `B77D 96D7 2F84 F36A CAA3 F872 9CBF 497D 829E E15A`
- Channels: `stable`, `beta`, `canary` (replace `stable` in the commands below)

```bash
# Debian, Ubuntu (APT)
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://packages.bobine.fit/bobine.gpg | sudo gpg --dearmor --yes -o /etc/apt/keyrings/bobine.gpg
echo "deb [signed-by=/etc/apt/keyrings/bobine.gpg] https://packages.bobine.fit/debian stable main" | sudo tee /etc/apt/sources.list.d/bobine.list
sudo apt update && sudo apt install bobine
```

```bash
# Fedora 41+, RHEL 10 (DNF 5)
sudo dnf config-manager addrepo --from-repofile=https://packages.bobine.fit/fedora/bobine-stable.repo
# Fedora 40 and earlier, RHEL 9 (DNF 4)
sudo dnf config-manager --add-repo https://packages.bobine.fit/fedora/bobine-stable.repo
sudo dnf install bobine
```

```bash
# Arch Linux (Pacman)
curl -fsSL https://packages.bobine.fit/bobine.gpg | sudo pacman-key --add -
sudo pacman-key --lsign-key B77D96D72F84F36ACAA3F8729CBF497D829EE15A
```

```ini
# /etc/pacman.conf, then: sudo pacman -Syu bobine
[bobine]
SigLevel = Required DatabaseOptional
Server = https://packages.bobine.fit/arch/stable/$arch
```

## This repository

- `index.html` and `fr/index.html` are generated by `node scripts/build-portal.mjs`; `node scripts/check-portal.mjs` checks them.
- The packages and their signed indexes live on the `gh-pages` branch, published by the workflows of the Bobine repository.
- `.github/workflows/verify-repo.yml` checks the key and signatures, then copies the portal pages to `gh-pages`.
